# COPO-IA 1.1.12 DEV9 — dossier de travail

- Si un dossier projet a été choisi et autorisé : Enregistrer un nouveau projet écrit directement dans ce dossier, sans fenêtre Enregistrer sous.
- Enregistrer sur un projet lié à un fichier réécrit celui-ci comme auparavant.
- Enregistrer une copie crée un fichier suffixé sans écraser une copie existante.
- Ouvrir .copo liste les projets du dossier mémorisé directement dans COPO-IA ; permet aussi le sélecteur système pour un autre dossier.
- Rouvrir le dernier projet relit le dernier fichier mémorisé, sous réserve de l'autorisation navigateur.
- Chrome/macOS peut réclamer de réautoriser le dossier après redémarrage : c'est une restriction de sécurité du navigateur, pas un chemin disque accessible à une page web.
- Aucune modification du moteur natif COPO-CNC 1.471 et de la logique géométrie/FAO.
- Validation statique uniquement : la recette utilisateur sur Chrome Mac reste requise.
