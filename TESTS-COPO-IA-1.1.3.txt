COPO-IA 1.1.3 BÊTA — Contrôles automatiques, 23 novembre 2026

Moteur project_11 : 12/12 tests réussis (tests/test-transaction11.cjs).
Enregistrement : 6/6 tests réussis (tests/test-save113.cjs).
Compatibilité statique du noyau intégré COPO 1.418 : 7/7 (tests/test-compatibility11.cjs).

Les tests du moteur utilisent des doublures de l’API COPO et ne remplacent pas
une simulation dans Chrome. Les tests d’enregistrement simulent les File System
Access APIs, ils ne manipulent pas de vrais fichiers sur Mac.

Les scénarios contrôlent :
- transaction CAO + FAO, modification et recalcul sélectif ;
- maintien des parcours non modifiés ;
- refus des opérations dangereuses ou périmées ;
- ordre des opérations par fraise ;
- comparaison FAO créée / recalculée / conservée ;
- aperçu DOM des paramètres de coupe et tracés XY sans rapides ;
- sauvegarde/copie avec extension .copo, annulation et erreurs sans écriture ;
- présence du noyau COPO 1.418 et des fonctions utilisées par l’extension.

Limites : la fenêtre Chrome/Mac 1.1.3, la simulation native et la sauvegarde sur
le Mac doivent être validées par l'utilisateur avant publication GitHub.
Aucun parcours/G-code qualifié pour une machine CNC réelle.
